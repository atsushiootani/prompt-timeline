# プロンプト・タイムラインを作る

`~/.claude/projects/*/*.jsonl`（Claude Code が自分のマシンに残す会話ログ）から
**その日に人が打ったプロンプト**だけを抜き出して、単体で開ける HTML に焼く。

- 縦 = 時刻、横 = セッション。丸 1 個がプロンプト 1 通、ひし形がスラッシュコマンド。
- 点にカーソルを重ねると本文、押すと下に全文が出る。
- **読むのはローカルのファイルだけ**。ネットワークへは出ないし、どこにも送らない。

前提: **Node 18 以上**。依存パッケージのインストールは要らない。

## 使うとき / 使わないとき

| | |
|---|---|
| 使う | 1 日（または任意の日）の作業を振り返りたい。どのセッションに時間を使ったか見たい。日報の材料がほしい |
| 使わない | 会話の中身を要約したい（これは点を打つだけで、要約はしない）。他人の記録を見たい（自分のマシンのログしか読めない） |

## 手順

### 1. どの日か決める

引数で日付が来ていればそれを使う。**無ければ今日**（`build` の既定）。
「昨日」「先週の金曜」等は `date` コマンドで具体的な `YYYY-MM-DD` に直してから渡す。

```bash
date -v-1d +%F        # macOS: 昨日
date -d yesterday +%F # Linux: 昨日
```

### 2. 作る

リポジトリのルート（この SKILL.md から見て `../../../`）で 1 本走らせる。

```bash
node bin/prompt-timeline.mjs build --date 2026-09-16
```

`out/<日付>.json` と `out/<日付>.html` が出て、最後に件数が出る:

```
human=96 slash=1 sessions=16
```

**その数をユーザーに伝える。** `human=0` なら、その日は記録が無いか
`--projects-dir` が違う。日付を取り違えていないか先に疑う。

出力先を変えたいときは `--out-dir <dir>`。

### 3. 開く

```bash
open out/2026-09-16.html      # macOS。Linux は xdg-open
```

返事には**ファイルパス（`file://…`）と件数**を書く。HTML は 1 枚で完結しているので
そのまま人に渡せる（ただし**本文がそのまま入っている**ので、渡す相手には注意する。下記）。

## よく使う指定

| やりたいこと | 足すもの |
|---|---|
| プロンプト本文を落とす（セッション名・ブランチ名は残る） | `--no-text` |
| 自動実行（SDK 経由・system 投入）も落とす | `--drop-sdk` |
| transcript の置き場が既定でない | `--projects-dir <path>` |
| 表示タイムゾーンを固定する | `--tz 9` |
| セッション名や色を自分で決める | `config/agents.json`（`config/agents.example.json` を写して編集） |

収集と生成を分けたいときは `collect` と `render` を個別に呼べる
（`node bin/prompt-timeline.mjs --help`）。

## 注意

- **出来た HTML には打った本文がそのまま入る。** 人に渡す・共有ディレクトリに置くときは
  中身を必ず確認するか、`--no-text` で焼き直す。`out/` は gitignore してある。
  なお `--no-text` が落とすのは本文だけで、**セッション名・ブランチ名は残る**。
- 日付は**ローカル時刻**で切る。UTC 23:30 のレコードは、+09:00 の環境では翌日に入る。
- 同じ会話が複数ファイルに写っていることがある（resume・ミラー）。
  `(時刻, 本文の先頭 80 字)` で重複を除いているので、**まったく同じ文を同じ秒に打つと 1 通に畳まれる**。
- サブエージェントが内部で投げた分は人の発話ではないので除外している。
